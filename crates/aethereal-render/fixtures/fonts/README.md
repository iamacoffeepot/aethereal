# Font fixtures

`NotoSans-Regular.ttf` is Noto Sans Regular, copied unchanged from Debian's `fonts-noto-core` package (`/usr/share/fonts/truetype/noto/NotoSans-Regular.ttf`, upstream https://github.com/notofonts/noto-fonts), licensed under the SIL Open Font License 1.1, whose text is in `OFL.txt`. The font module's tests read it: it has TrueType outlines, composite glyphs, and pair kerning in `GPOS` of both formats.
